# Führerschein-Automatisierung

## Projektbeschreibung

Eine selbst entwickelte Desktop-Anwendung zur Automatisierung einer Führerschein-Lernsoftware.

Die Anwendung nutzt **ClickClickDrive** als externe Informationsquelle, um die passenden Antworten zu Führerscheinfragen automatisch zu finden und auszuwählen.

## Funktionen

- Automatische Erkennung der aktuellen Führerschein-Fragennummer
- Suche nach der entsprechenden Frage auf ClickClickDrive
- Automatisches Ermitteln der richtigen Antwort
- Selbstständiges Markieren der passenden Antwort
- Automatisches Wechseln zur nächsten Frage
- Automatisches Überspringen von Videofragen
- Steuerung und Unterbrechung über die geöffnete CMD-Konsole

## Technischer Hintergrund

Das Projekt verbindet die Automatisierung von Desktop-Interaktionen mit der Suche nach Informationen auf einer externen Website.

Besonderes Augenmerk lag auf der Automatisierung wiederkehrender Abläufe und der Möglichkeit, den Prozess bei Bedarf manuell zu unterbrechen.

## Projektinformationen

- **Projekttyp:** Eigenentwicklung
- **Bereich:** Desktop-Automatisierung
- **Plattform:** Windows
- **Externe Datenquelle:** ClickClickDrive
